# PC Monitor

Лёгкий виджет и индикатор в системном трее Windows, который показывает, чем занят компьютер, и помогает найти «забытые» и зависшие процессы — особенно когда одновременно открыто много проектов, IDE, браузеров и LLM-инструментов (Claude Code и т. п.).

A small Windows tray indicator and desktop widget that shows what is loading your PC and helps you spot forgotten or hung processes from dev tools, IDEs, browsers and LLM CLIs.

## Возможности

- **Индикатор в трее** (слева от часов): цветной значок с процентом самой загруженной метрики. Зелёный — норма, жёлтый — повышенная нагрузка (от 70%), красный — перегрузка (от 90%). Уведомление при перегрузке с указанием самого «тяжёлого» процесса.
- **Виджет на экране:** компактное тёмное окно поверх остальных — CPU, RAM, GPU, диск, скорость сети и аналоговый стрелочный индикатор скорости интернета (шкала логарифмическая, стрелка усредняет последние ~4,5 с). Перетаскивается мышью в любое место, положение запоминается.
- **Тест интернета:** кнопка «⚡ Тест» в виджете (и в панели). Измеряет пинг, джиттер, скорость скачивания и отправки через `speed.cloudflare.com`; во время теста показаны два аналоговых индикатора («Чтение» и «Передача») и поэтапный текст, рядом кнопка «📋» — отчёт последнего теста (история — в панели). Тест расходует до ~150 МБ трафика.
- **Сканер CPU** (тонкая полоса внизу виджета, видна всегда): график загрузки CPU за последние ~60 отсчётов с бегущим лучом и вспышкой при каждой проверке процессов. Интервал проверки — выпадающее меню «Проверка CPU» (30 с, 1–10 мин), выбор запоминается (`scanSec`). Если один процесс держит больше `hogCpu` % всего CPU не меньше `hogMinSec` секунд и две проверки подряд, в полосе появляется рекомендация: имя процесса, CPU, как долго держит, кнопки «Завершить» (с диалогом подтверждения) и «Позже» (скрыть на 30 мин). Свои процессы, системные и фоновые службы (антивирус, индексатор и т. п.) не предлагаются. Каждая проверка — тот же скан процессов через PowerShell, поэтому при 30 с он заметнее, чем при 1–10 мин.
- **Панель деталей** (клик по значку в трее):
  - процессы, сгруппированные по проектам;
  - блок подозрительных процессов: «не отвечает», «осиротевший?», «простаивает, но держит память», «держит CPU»;
  - блок **LLM: инструменты и модели** — Claude, Codex CLI, Gemini CLI, aider, ChatGPT Desktop, Ollama, LM Studio (процессы, память, CPU, время работы) и загруженные локальные модели Ollama / LM Studio с занятой памятью и кнопкой «Выгрузить» (Ollama);
  - блок **Расход токенов** (локально, без API-ключей): сколько токенов потратили Claude Code и Codex сегодня, за последние 5 часов и за 7 дней (новые / выходные / из кэша), разбивка по проектам, оценка «≈$ по прайсу API», а для Codex — реальный остаток лимитов из его журналов. Считается инкрементально по журналам сессий; тексты сообщений не читаются и не сохраняются;
  - блок **Расход по API (организация)**: расход Anthropic и OpenAI за месяц, 7 дней и сегодня (OpenAI), токены и разбивка по моделям. Нужны Admin-ключи организации; вводятся в панели («Ключи API»), хранятся только на этом ПК, зашифрованы средствами Windows (DPAPI) и уходят только на `api.anthropic.com` / `api.openai.com`. Личные аккаунты и тариф Team для этих API недоступны. У Anthropic данные отстают до 24 часов;
  - сессии CLI-инструментов (Claude Code по `~/.claude/projects`, Codex по `~/.codex/sessions`);
  - сводка по браузерам;
  - кнопка завершения процесса с подтверждением (процесс и его дочерние процессы; системные процессы защищены).
- **Блок «Фокус»** (необязательный; выключается целиком или по разделам — в «Настройках блока» панели или пунктом «Блок «Фокус»» в меню трея). Данные хранятся локально в `focus.json` рядом с `settings.json`, в сеть не уходят:
  - Секции «Мотиватор дня», «Съесть лягушку», «Цель дня», «Изучаем язык» и «Привычки» (кнопки своих привычек на виджете) отключаются по отдельности в меню трея и по правому клику на виджете; настройки блока — внизу списка панели;
  - **Мотиватор дня** — фраза на немецком, перевод по клику, 🔄 — другая;
  - **Изучаем язык** — немецкое слово, перевод по клику, ✓ — выучил; счётчик «за день / за месяц»;
  - **Помидор** — у каждой лягушки прогноз 15–40 мин (клик меняет), «▶ Начать», обратный отсчёт, счётчик 🍅 и уведомление по окончании;
  - **Лягушки дня** — 1–5 самых неприятных задач на сегодня (лимит `frogsMax`, по умолчанию 2). Невыполненные со вчера предлагаются «перенести на сегодня» или убрать. Подзадачу цели можно сделать лягушкой кнопкой 🐸; когда лягушка съедена, подзадача отмечается выполненной;
  - **Привычки** — ежедневные отметки с серией дней и неделей-индикатором; по умолчанию «Немецкий» (15 мин). Можно добавить свои привычки; если в названии есть «фразы», кнопка привычки открывает немецкую фразу с переводом по клику;
  - **Цели и подзадачи** — прогресс в процентах, подсветка следующего шага, порядок меняется стрелками ↑↓. **Цель дня** на виджете — одна цель и её следующий шаг: шаг можно отметить или сделать лягушкой, цели чередуются по дням, ↻ — другая;
  - **Мотивация и рекомендации** — одна самая важная прямая рекомендация по правилам, без сети и LLM; срочная рекомендация показывается и в виджете. Раз в день, начиная с `remindHour`, при необходимости приходит уведомление Windows;
  - всё добавляется, редактируется (✎) и удаляется; удаление привычки и цели — в два клика.
- **Минимальная нагрузка:** адаптивный опрос (реже, когда окна скрыты), одно обращение к системе для списка процессов, панель освобождает память после закрытия.

## Запуск из исходников

Нужны Windows 10/11 и Node.js 20+.

```bash
npm install
npm start
```

## Сборка дистрибутива

```bash
npm run dist
```

Готовые файлы появятся в папке `dist` (portable `.exe` и установщик).

## Настройки

Файл настроек открывается из меню трея (правая кнопка → «Открыть файл настроек»):

| Параметр | Назначение |
| --- | --- |
| `warn`, `crit` | пороги CPU/RAM/GPU, % (по умолчанию 70 / 90) |
| `diskWarn`, `diskCrit` | пороги заполнения диска, % (85 / 95) |
| `projectRoots` | корневые папки проектов для группировки процессов |
| `notify` | уведомления о перегрузке |
| `scanSec` | интервал проверки сканера CPU, секунды: 30, 60, 120 … 600 (по умолчанию 60; меняется меню в виджете) |
| `hogCpu` | порог рекомендации: доля процесса от всего CPU, % (30) |
| `hogMinSec` | сколько секунд процесс должен держать `hogCpu`, чтобы появилась рекомендация (60) |
| `budgets` | свои лимиты токенов Claude Code: `claude5h`, `claudeDay`, `claudeWeek` (0 — выключено). При заданном лимите в панели появляется полоска остатка |
| `budgets.anthropicMonth`, `budgets.openaiMonth` | месячный бюджет API в USD (0 — выключено): полоска расхода в блоке «Расход по API» |

| `focus` | блок «Фокус»: `enabled`, `frogs`, `lang`, `habits`, `goals`, `phrase` (показ разделов), `frogsMax` (1–5), `remindHour` (час напоминания, 14), `notify` (уведомление). Меняется в панели |

Свои слова и фразы для блока «Фокус» можно править в `src/focus-data.js`. Проверка логики блока: `node tools/test-focus.js`.

Меню трея: показать/скрыть виджет, уведомления, секции и весь блок «Фокус», автозапуск, выход. Двойной клик по значку — показать виджет.

## Ограничения

- Windows не отдаёт рабочую папку процесса, поэтому привязка к проекту — эвристика: по путям в командной строке и по времени запуска `claude.exe` относительно логов сессий.
- Точные вкладки браузера не определяются (показаны процессы браузера целиком).
- Нагрузка GPU считается через счётчики Windows (`GPU Engine`), доступны любые видеокарты.
