# PC Monitor

Лёгкий виджет и индикатор в системном трее Windows, который показывает, чем занят компьютер, и помогает найти «забытые» и зависшие процессы — особенно когда одновременно открыто много проектов, IDE, браузеров и LLM-инструментов (Claude Code и т. п.).

A small Windows tray indicator and desktop widget that shows what is loading your PC and helps you spot forgotten or hung processes from dev tools, IDEs, browsers and LLM CLIs.

## Возможности

- **Индикатор в трее** (слева от часов): цветной значок с процентом самой загруженной метрики. Зелёный — норма, жёлтый — повышенная нагрузка (от 70%), красный — перегрузка (от 90%). Уведомление при перегрузке с указанием самого «тяжёлого» процесса.
- **Виджет на экране:** компактное тёмное окно поверх остальных — CPU, RAM, GPU, диск, скорость сети и аналоговый стрелочный индикатор скорости интернета (шкала логарифмическая, стрелка усредняет последние ~4,5 с). Перетаскивается мышью в любое место, положение запоминается.
- **Панель деталей** (клик по значку в трее):
  - процессы, сгруппированные по проектам;
  - блок подозрительных процессов: «не отвечает», «осиротевший?», «простаивает, но держит память», «держит CPU»;
  - сессии Claude Code (по логам в `~/.claude/projects`);
  - сводка по браузерам;
  - кнопка завершения процесса с подтверждением (процесс и его дочерние процессы; системные процессы защищены).
- **Минимальная нагрузка:** адаптивный опрос (реже, когда окна скрыты), одно обращение к системе для списка процессов, панель освобождает память после закрытия.

## Запуск из исходников

Нужны Windows 10/11 и Node.js 20+.

```bash
npm install
npm start
```

## Сборка дистрибутива

```bash
npm run dist
```

Готовые файлы появятся в папке `dist` (portable `.exe` и установщик).

## Настройки

Файл настроек открывается из меню трея (правая кнопка → «Открыть файл настроек»):

| Параметр | Назначение |
| --- | --- |
| `warn`, `crit` | пороги CPU/RAM/GPU, % (по умолчанию 70 / 90) |
| `diskWarn`, `diskCrit` | пороги заполнения диска, % (85 / 95) |
| `projectRoots` | корневые папки проектов для группировки процессов |
| `notify` | уведомления о перегрузке |

Меню трея: показать/скрыть виджет, уведомления, автозапуск, выход. Двойной клик по значку — показать виджет.

## Ограничения

- Windows не отдаёт рабочую папку процесса, поэтому привязка к проекту — эвристика: по путям в командной строке и по времени запуска `claude.exe` относительно логов сессий.
- Точные вкладки браузера не определяются (показаны процессы браузера целиком).
- Нагрузка GPU считается через счётчики Windows (`GPU Engine`), доступны любые видеокарты.
